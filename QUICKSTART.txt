DEPLOYING TO PRODUCTION (Choose One):
═════════════════════════════════════════════════════════════════════════════

Option A: GitHub + Netlify (EASIEST, 1 hour, fully automated)
  1. Push code to GitHub
  2. Add 3 secrets (API key, Netlify token, Netlify site ID)
  3. Move .github_workflows_ai_trends.yml to .github/workflows/
  4. Done — runs every Sunday 6 PM UTC automatically
  → See SETUP.md "Option A: GitHub + Netlify"

Option B: AWS Lambda (45 min, serverless, reliable)
  1. Create Lambda function, add environment variables
  2. Add EventBridge trigger (cron schedule)
  3. Upload zip with code + dependencies
  → See SETUP.md "Option B: AWS Lambda"

Option C: Local Cron (Simple, no cost, manual-ish)
  1. Add to crontab: "0 18 * * 0 cd /path && python3 ai_trends_production.py"
  2. Manually run `netlify deploy --prod` after each run
  → See SETUP.md "Option C: Local Cron"

TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════════

  "Could not resolve authentication method"
    → Set ANTHROPIC_API_KEY environment variable
    → echo $ANTHROPIC_API_KEY to verify

  "No items found"
    → RSS feeds might be down temporarily
    → Check internet connection
    → Try running again in 5 minutes

  "Scoring takes too long"
    → Normal, Claude API is slow for 20+ items
    → Lambda timeout is 60 seconds (usually enough)
    → Local runs can take 2-5 minutes

  "Dashboard not updating after deploy"
    → Check GitHub Actions logs for errors
    → Verify NETLIFY_SITE_ID is correct
    → Try manual: netlify deploy --prod

  See SETUP.md for more troubleshooting.
